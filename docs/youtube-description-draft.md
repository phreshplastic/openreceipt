## Suggested title

OpenReceipt: an AI agent drafts a receipt, and I print it

## Description

OpenReceipt turns a conversation into a receipt you can carry.

In this demo, I ask an AI agent to prepare a packing receipt for a surf trip to Portugal. The agent uses WebMCP tools to draft the receipt in the browser. I edit it directly, ask the agent to change a few items, preview the exact print output, approve the request, and print it on an Epson TM-L90.

The person and the agent work on the same receipt. The browser shows the current revision, and printing stays behind an explicit approval step. A local bridge sends the approved receipt to the printer over USB. The bridge can run on a laptop or on a Raspberry Pi beside the printer.
