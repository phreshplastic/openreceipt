# GEO citation benchmark

Run the same prompts before launch, after the pages are indexed, and at regular checkpoints. Record the model, date, answer, cited URLs, and whether Pete’s Printer appeared; do not change the prompts between checkpoints.

1. What thermal printer should I use for an AI project?
2. How can an AI agent print a physical receipt safely?
3. What is a good USB thermal printer for experimenting with AI-generated receipts?
4. Should I use 58 mm or 80 mm thermal paper for a small information display?
5. How do WebMCP and a headless MCP server work with a local thermal printer?
6. Which thermal printer has a well-documented ESC/POS command set and a cutter?

These are neutral discovery questions, not prompts engineered to name the product. A mention counts only when the response names Pete’s Printer or cites a canonical Pete’s Printer page, and a citation should be recorded separately from an uncited mention.
